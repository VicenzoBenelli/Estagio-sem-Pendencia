# Instruções operacionais para agentes

1. Leia `AGENTS_CONTEXT_Estagio_sem_Pendencia.md` antes de planejar ou implementar uma task ESP e consulte também o código e o card correspondente.
2. Não presuma que funcionalidades futuras já existem, não invente requisitos institucionais e não implemente nada fora do escopo da task atual.
3. Aprovação documental não é autorização oficial de estágio. Quando houver operações privilegiadas, a autorização deverá ser garantida no backend.
4. Não armazene credenciais administrativas em clientes Flutter; use dados fictícios em testes e preserve o histórico documental e o versionamento quando essas funcionalidades forem desenvolvidas.
5. Respeite o fluxo Git `branch individual → homolog → main`, use mensagens de commit em português e não execute operações destrutivas de Git sem autorização.
6. Execute os testes pertinentes e informe somente resultados reais, com limitações conhecidas.
